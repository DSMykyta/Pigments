# OLD DRAFTS

Тут лежать старі робочі тексти: попередні лорбуки, сцени, серії, нотатки, PDF і спортивна документація.

Це не сміття. Це архів чернеток. Просто тепер головною точкою входу є `LORE_SYSTEM`.

## Що тут

- `system.md`, `lore.md`, `PANTONE.md` - старі канонічні нотатки, з яких зібрана нова компактна система.
- `series.md`, `Serias`, PDF-глава - проза і структура серій.
- `TOKYO_ONI.md` - основа спортивної гілки.
- `OST.md` - атмосферні й музичні матеріали.
- `Aclecchat*.txt` - сирі чат-нотатки.
- `Shop` - порожній старий файл-заготовка.

## Як користуватись

Якщо в `LORE_SYSTEM` чогось бракує, шукай тут першоджерело і перенос короткою тезою назад у відповідний файл нової системи.
