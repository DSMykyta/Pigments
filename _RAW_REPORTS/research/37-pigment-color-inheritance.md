# Успадкування кольору пігменту: математика і практика

---

## Принцип RGB-змішування

```
R_child = (R1 + R2) / 2
G_child = (G1 + G2) / 2
B_child = (B1 + B2) / 2
```

**Ключове обмеження:** `V_child ≥ max(V1, V2) / 2`

Щоб дитина мала V < 20%: жоден з батьків не може мати V ≥ 40%.
Два батьки одного відтінку → дитина V < 20 неможлива через змішування.
