# RAW REPORTS

Тут лежить дослідницька сировина: великі AI-звіти, тематичні розвідки й агрегатори.

Це не робочий канон. Використовуй як довідник, коли треба розширити конкретну тему.

## Що тут

- `research` - найбільша серія докладних звітів.
- `Claude Ai` - коротша тематична серія на 33 файли.
- `research_ALL.md`, `Cloude_AI_ALL.md`, `research_25-33.md` - агрегатори, тобто зручні для пошуку, але дублюють інші матеріали.
- `deep-research-report-chatgpt.md` і `compass_artifact...md` - окремі аналітичні звіти.
- `INBOX_DUMP_EXTRACTS` - очищені текстові витяги з Claude-дампу `INBOX_DUMP`, з індексом для пошуку.

## Як користуватись

Спершу дивись `LORE_SYSTEM`. Сюди заходь тільки коли треба витягнути деталі, приклади, політичні наслідки або додаткові формулювання.
