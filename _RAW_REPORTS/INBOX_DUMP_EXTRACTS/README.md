# INBOX_DUMP_EXTRACTS

Це очищені витяги з Claude-дампу `INBOX_DUMP`.

Сирий дамп лишився у `INBOX_DUMP`. Тут лежать markdown-файли з видимими повідомленнями й `index.csv` для пошуку.

## Як користуватись

1. Спершу дивись `LORE_SYSTEM`.
2. Якщо треба перевірити джерело факту, відкрий `index.csv`.
3. Потім відкривай конкретний markdown-файл.

## Статус

Це не канон. Частина тексту - прямі слова автора, частина - відповіді Claude, частина - помилки й невдалі додумки. У канон переносити тільки після звірки.
