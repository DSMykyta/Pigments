## Образ

Темна борода з сивиною, динамічна низька стійка, впевнена усмішка. Номер 00 працює як знак "точки відліку".

## Функція в команді

Matadors мають капітана-MEND, тобто лідерство не через завершення атаки, як у Photons, і не через читання, як у Oni, а через підтримку й утримання команди цілою.
