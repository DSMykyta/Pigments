# Showbiz Core Index

Світовий шоу-біз лору Пігментів — це мережа, де слава формується на перетині таланту, пігментної класифікації, медіа-інфраструктури, бренд-контрактів і сімейного капіталу. Він охоплює кіно, музику, спорт, fashion/luxury, beauty, red carpet, стрімінг, таблоїди та кризовий PR.

Пігменти впливають на кар’єри нерівномірно: для одних це конкурентна перевага, для інших — стигма, нагляд або політичний ризик. Непегментні еліти водночас можуть концентрувати структурну владу через медіа-власність, бренди й доступ до інституцій.
